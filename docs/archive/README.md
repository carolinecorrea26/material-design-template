# Archived migration reports

Historical phase, Step 3–6, canonical/MCR, active-site, legacy-platform and ASCE handoff
reports from before the fresh-start requirements model. They are kept for traceability:
code and generated catalog records cite them as `source`/`reference` evidence.

They do not describe current behavior. For current work see:

- [Requirements specification](../requirements-spec/README.md) and [`requirements/`](../../requirements/)
- [ASCE execution register](../asce-follow-up-execution.md)
- [Approved ASCE business decisions](../asce-business-decisions.md) and
  [provisional source decisions](../step3-provisional-decisions.md)
- [Portal Library acceptance criteria](../portal-library-acceptance.md)

Some links inside these reports point to files removed in earlier cleanups (Postgres
validation outputs, schema audits); those are recoverable from git tag `archive/sql-postgres-v5`.
The generator scripts for these reports (`audit-active-sites.mjs`,
`review-active-site-adoption.mjs`, `write-canonical-report.py`) were retired.
