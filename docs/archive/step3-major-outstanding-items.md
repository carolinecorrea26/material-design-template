## Confirmed PRASE and reference rate table behavior

User clarification, October 2, 2026:

- Clients have a configurable **rates configured in PRASE** setting. The global default is **No**. The current business clients use **Yes**, except CSEA, which uses **No**. This describes capability, not proof that a real rate service is connected or a premium is available.
- When **Yes**, clients may enable the quote tool and estimates on Coverage. These are separate presentation choices; actual prices still require a verified rate response.
- When **No**, hide the quote tool and all calculated rate displays automatically, and use the homepage **hero image** variant.
- A client without PRASE rates may optionally configure a reference rate table, such as a PDF, image or HTML table. Replace the estimated-rate display with a **View rate table** link that opens the existing drawer component.
- Without a configured reference table, hide the estimated-rate area; do not invent a table or show an empty link. A reference table is not a calculated quote.

CSEA's rate presentation is clarified. Its occupation-based benefit amounts and included riders remain open below. The authoritative CSEA table asset has not yet been supplied. Draft editing, publication and live activation belong to later steps; Step 3 can store and execute the presentation policy without cutting over the live form.
