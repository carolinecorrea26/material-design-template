# Global template capability review

Storybook documents shared structures and meaningful variations rather than
copying examples per Site. All ten business Sites are now enrolled; the source
folders determine enrollment. The generated capability register distinguishes
matched effective assignments from synthetic global examples.

Global definitions and supported overrides own fields and composition. Canonical
component source, dependencies and examples are declared once; the generated
component catalog and source-tracing audit verify their current links. Page
controllers use the same global renderer registry in routed and embedded layouts.

Use `npm run storybook:template:check` to verify references. The component
reuse/documentation review remains accepted; no repeat approval of equivalent
fields, names, utility headers or whole pages is implied by another Site's values.
See [component documentation](component-documentation.md) and
[effective Sites](../requirements-spec/sites.md).
