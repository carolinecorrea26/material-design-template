# Accessibility reference

This Library section has no runtime catalog tables yet and is intentionally absent from `manifest.json`. Missing results do not indicate a passing assessment.

The existing sources are [criteria](../../../src/content/docs/accessibility.ts), [review concerns](../../../src/content/docs/accessibilityConcerns.ts), and the [Library presentation](../../../src/pages/admin/library/AccessibilityLibrary.tsx). They record the WCAG 2.2 AA target and pending review, not completed conformance. Siteimprove tracking setup remains pending. Automated checks do not replace keyboard, screen reader and complete-journey acceptance.

If assessment records are introduced later, define their persistence contract and validation before registering their authoring tables in the manifest/build mapping.
