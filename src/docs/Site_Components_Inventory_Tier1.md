# Site Components Inventory — Tier 1: Layout & UI

> Extends: _Portal Template Design — Claude Enterprise Handoff_
> Schema source: Requirements doc § 3. Build the Site Components requirements inventory
> Scope: `layout/` and `ui/` component categories
> Status: Draft — items marked ⚠️ are open questions requiring source confirmation

---

## How to read this document

- Each component is documented **once**. Usage locations are listed in **Pages / Locations**.
- "Client Configurable" means the behavior or appearance can differ per client via config, not code changes.
- Component IDs use the pattern `LAY-###` (layout) and `UI-###` (ui).
